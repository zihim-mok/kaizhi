# 六步流程

每步都有验收标准。**没过验收不要进下一步** —— 后面所有工序都建立在前一步上，返工代价是指数级的。

---

## 1. 定选题

**动作**：填完 [五栏选点表](01-method.md#五栏选点表)。选可视化形式（点阵 / 条形 / 时间轴 / 节点链）。

**验收**：
- [ ] 知识点能一句话说完，不超过 25 字
- [ ] 反差点是"跟直觉相反的那半句"，不是知识点本身
- [ ] 可视化形式只选了一种（最多混两种）

**耗时**：10 分钟。这一步花的每一分钟，都在后面省十分钟。

---

## 2. 核数据

**动作**：把表里的每个数字查清出处，算清比例。

**验收**：
- [ ] 每个数字有来源（书名、页码、链接、自己导出的表格）
- [ ] 主要比例能手算出来，且和文案里说的一致
- [ ] 查不到的**留白**，不估算、不硬填

> 真实案例：目录学那期需要《隋志》子部和集部的卷数，查了多个来源都没给确切值。最终卡片上只放类数（子 14 类、集 3 类），卷数位置留空。宁可少一个数字，不能被评论区抓到编造。

**耗时**：20–60 分钟，取决于题材。历史类题材这一步最重。

---

## 3. 写分镜

**动作**：写两张表 —— 场景表（`SCENES`）和字幕稿（`CUES`）。

场景表格式：

```
{ s: 0, t0: 0,   t1: 6   },   // 钩子：两行大字，无字幕
{ s: 1, t0: 6,   t1: 26  },   // 书墙：288 格熄灭九成
{ s: 2, t0: 26,  t1: 66  },   // 公元前 26 年
```

字幕稿格式（绝对秒数，一句话一屏）：

```js
const CUES = [
  [6.40, 10.20, '《汉书·艺文志》，中国现存最早的图书目录'],
  [10.40, 14.20, '它记了 <b>596 家</b>、<b>13269 卷</b>'],
];
```

**验收**：
- [ ] 场景时间首尾相接，无缝隙、无重叠，最后一场 `t1` = `TOTAL`
- [ ] 每条字幕 8–16 字，超过 16 字会被自动断行（见 [排版](04-typography.md)）
- [ ] 字幕之间留 0.2–0.4 秒空隙，不要首尾相接（视觉上像卡顿）
- [ ] **画面文字和字幕没有一句重复**
- [ ] 长版：每 40 秒内至少一个新信息

**字幕写多长的换算**：中文口播约每分钟 240–280 字。6 分半 ≈ 1700 字上限；实际用了 71 句 × 14 字 ≈ 1000 字，留了呼吸空间。**不要写满**，写满了就没有停顿，观众会累。

---

## 4. 生成 HTML

**动作**：从模板起步，或直接让 AI 按 [提示词](../prompts/) 生成。

**验收**：
- [ ] 单文件，无 CDN、无外部字体、无图片外链
- [ ] `node tools/check-js.mjs file.html` 语法通过
- [ ] 顶部有 `CONFIG` / `SCENES` / `CUES` 三块，内容与样式分离
- [ ] 支持 `?t=秒数` 跳转、`?p` 暂停、`?clean` 隐藏提示

**为什么必须单文件**：录屏时任何一次加载失败、字体回退、图片 404，都会毁掉整条录制。单文件 = 零网络依赖 = 零意外。

---

## 5. 逐帧验证

**动作**：按时间点批量截图，一帧一帧看。

```bash
node tools/snap.mjs templates/long-narrative.html 4 20 48 120 200 284 393
```

**验收**（每一帧都要过）：

| 检查项 | 怎么判断 |
|---|---|
| 溢出 | 内容是否被底部字幕压住、是否超出画布 |
| 空屏 | 内容是否全挤在顶部、中下部大片空白 |
| 断行 | 有没有断在词中间（"每一种 / 书"） |
| 复读 | 画面上的字和字幕是不是同一句 |
| 孤字 | 最后一行是不是只剩一两个字 |
| 数字 | 条形长度和标注的数字是否成比例 |

**这一步不能省。** 眼睛回放会漏掉一闪而过的排版问题，截图看得见。

---

## 6. 录制发布

**动作**：浏览器全屏 → 隐藏提示 → 录屏 → 后期加 BGM。

**验收**：
- [ ] 画面 9:16，无浏览器 UI、无鼠标光标
- [ ] 右下角快捷键提示已隐藏（按 `H`，或网址加 `?clean`）
- [ ] 总时长与 `TOTAL` 一致
- [ ] 中途没有切窗口（切窗口会让 rAF 掉帧跳画面）

**录制注意事项**：
- 时间轴挂在真实时钟上（`performance.now()`），所以卡顿只会**跳帧**，不会拖慢整片。总长永远等于 `TOTAL`
- 但跳帧会丢内容。录之前关掉其他标签页、别开视频会议
- 建议 60fps 录制。30fps 下描线动画会看起来一顿一顿

**如果要配音**：画面是录死的，配音只能反过来贴画面。按 `export-cues.mjs` 出的 SRT 逐句念，或先把 SRT 导进剪映对着时间轴念。念快了空场，念慢了串句。
