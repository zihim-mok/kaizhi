# 方法论：先想清楚，再动手

## 一句话法则

> 一个知识点，做成一张会动的图，最后落一句结论。

拼的不是技术。是把一个点讲出**反差**的本事。任何一期内容的成败，90% 在做图之前就定了。

## 五栏选点表

填不出来就别开工。这张表填完，等于分镜写完一半。

| 栏位 | 填什么 | 反例 | 正例 |
|---|---|---|---|
| **知识点一句话** | 只讲一个点，一句话说完 | 中国古代目录学的发展 | 八成订单来自两成客户 |
| **反差点** | 跟直觉相反的那半句 | 客户很重要 | 重要的客户，其实是少数 |
| **真实数据** | 自己手里的真数，先核完再填 | 大约八成 | 100 个客户，前 20 名占 68.8 / 86 万 |
| **可视化形式** | 点阵 / 条形 / 时间轴 / 节点链，四选一 | 做个炫酷动画 | 10×10 点阵逐个点亮 |
| **第一句** | 就是反差句本身 | 大家好今天讲 | 八成的订单，来自两成客户 |

**最容易翻车的是第三栏。** 数据没核完就开始画，画到一半发现比例不对，整张图重做。先把数算明白：68.8 ÷ 86 = 80%，这部分占两成，两个数得能对上，否则观众一算就露馅。

## 反差从哪来

三种，按可靠性排序：

**1. 比例反差（最稳）**
用真数据算出一个不成比例的比值。20% 的客户 → 80% 的订单；7 部史书里的艺文志，管着两千年的书账。

**2. 时间反差**
现在看到的和两百年前一样 / 不一样。
「算法每天做的判断，和公元前 26 年刘向做的，是同一件事。」

**3. 身份反差**
你以为属于 A 的东西，其实属于 B。
「这不是一份书单，是一份取舍名单。」

三种可以叠加。叠加时注意：**一期只留一个反差点**，两个会互相稀释。

## 短版的骨架（15–40 秒）

四拍，缺一不可：

```
0–3 秒   抛出反差句（不需要铺垫，观众没有耐心）
3–8 秒   建立画面（点阵出现、所有元素就位，全是灰的）
8–20 秒  过程（逐个点亮，数字同步跳）
20–25 秒 落结论（一句话 + 画面压暗，把视线全部交给这句话）
```

关键：**过程必须可数**。点亮 20 个点，观众会跟着数；如果一次全亮，就没有"积累"的体感，结论也就没有分量。

## 长版的骨架（5–8 分钟）

长版不能靠一个奇观撑住，必须有一条叙事线。经验值：**每 40 秒得有一个新信息**，否则观众走。

以目录学那期（6 分 36 秒）为例，10 个场景的配速：

| 时长 | 场景 | 作用 |
|---|---|---|
| 6 秒 | 钩子 | 无字幕，两行大字，直接抛问题 |
| 20 秒 | 奇观 | 288 格书墙熄灭九成，把抽象数据变成视觉冲击 |
| 40 秒 | 起点 | 公元前 26 年，一个人开始整理书 |
| 40 秒 | 第一次分类 | 《七略》：按学派而非学科 |
| 45 秒 | 制度化 | 目录被写进正史，成了国家行为 |
| 50 秒 | 体系定型 | 经史子集，四部分类法 |
| 50 秒 | 理论化 | 章学诚：辨章学术，考镜源流 |
| 70 秒 | 高潮 / 反转 | 四库全书：著录 3461，存目 6793 |
| 50 秒 | 拉回当代 | 算法推荐做的是同一件事 |
| 29 秒 | 收尾 | 大字，字幕留白 |

**两个结构上的决定值得抄：**

**钩子不放字幕。** 前 6 秒只有画面文字，观众被迫读字，注意力被锁死。加了字幕反而变成"两条信息抢注意力"。

**高潮放在 2/3 处，不是结尾。** 四库那段的"存目是收录的两倍"，是全片信息密度最高、情绪最强的地方，放在 4 分 11 秒。之后的当代对照和收尾都是它的余震。把最强的放在最后，观众撑不到。

## 两次反转

单次反转只能撑 30 秒。要撑 6 分钟，需要第二次反转来**推翻第一次的结论**。

目录学那期的结构：

> **第一次反转**：现存最早的图书目录，记的大多是已经消失的书。596 家、13269 卷，今天十不存一 —— 所以目录是**文明的备份**。
>
> **第二次反转**：但备份的同时，它也是一份**取舍名单**。《四库全书》著录 3461 种，存目 6793 种。"存目"就是"知道有这本书，但不收"。收什么、不收什么，是排序的权力。

第一次建立意义（这件事很重要），第二次拆掉它（这件事没那么干净）。有这两层，冷门学科才能变成一个关于**记忆与筛选**的普遍问题。

**写不出来第二次反转怎么办？** 说明这个题材只够做短版。不要硬凑。

## 选题自检

动手前问四句，有一个答不上就换题：

1. 这个知识点能用**一句话**说完吗？
2. 这句话里有**数字或对比**吗？
3. 这个反差点，需要专业知识才能理解吗？（需要 → 太重，再削）
4. 我能画出**一张图**吗？（画不出 → 换可视化形式，或换题）

第 4 条特别关键。可视化形式只有四种基本型，选错了会做得很痛苦：

| 形式 | 适合表达 | 例子 |
|---|---|---|
| 点阵 | 比例、少数与多数 | 288 格书墙、100 个客户 |
| 条形 | 两者对比、差距 | 著录 3461 vs 存目 6793 |
| 时间轴 | 演变、断裂 | 七部正史的知识账本链 |
| 节点链 | 流程、传承 | 刘向 → 刘歆 → 班固 |

一张图里最多混两种。混三种就变成信息图，不是动画了。
