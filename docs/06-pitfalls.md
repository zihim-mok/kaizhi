# 踩坑清单

全部来自实际交付过程中的翻车记录。每条格式：**现象 → 原因 → 解法**。

---

## 一、版面

### 内容全挤在顶部，中下部大片空白

**现象**：画面像只加载了一半。
**原因**：`flex-direction:column` 但没写 `justify-content`，默认从顶部堆。
**解法**：

```css
.scene{
  display:flex; flex-direction:column;
  justify-content:center;      /* 必须显式写 */
  padding:86px 84px 340px;     /* 底部给字幕留 340px */
}
```

### 内容被底部字幕压住

**现象**：字幕浮在数据卡片上，两者叠在一起。
**原因**：内容的 padding-bottom 小于字幕区高度（196px + 104px = 300px）。
**解法**：底部 padding 至少 340px，且内容高度不超过 1450px。**该删内容就删，不要靠缩字号硬塞。**

### 120px 的大字 + 并排元素导致换行

**现象**：「公元前 26 年」的"年"字掉到了下一行。
**原因**：120px 的大字 + 210px 的插图超过了 912px 版心。
**解法**：把插图挪成**绝对定位的角标**（`.art-tr`，`right:84px; top:128px`），不占内容流。任何"图和字并排"的布局，都要先算总宽。

### 结尾字幕与结论卡抢同一块地方

**现象**：最后一句字幕和结论卡叠在一起，两层字互相穿透。
**原因**：结论卡通常就放在字幕区（`bottom:92px`），出现时间一旦和最后一句重叠就必然撞。
**解法**：最后一句必须在结论卡出现**之前**说完 —— 结论卡接管字幕位，成为唯一的落点。短版模板里：

```js
conclude: 18.8,                                   // 结论卡出现
[15.60, 18.40, '剩下那些，其实可以不干'],          // 最后一句 18.4 收尾，留 0.4 秒空档
```

顺带一个好处：字幕不报数字，数字由结论卡给出，两边自然不复读。

## 二、字幕

### 断在词中间

**现象**：「刘向领了活：每一种 / 书，校勘、编目」。孤零零一个"书"。
**原因**：中文浏览器允许任意字间断行。
**解法**：`.cue` 上加 `text-wrap:balance`，同时用 [断行函数](04-typography.md#中文断行) 强制只在标点后断。

### 破折号被拆成两行

**现象**：「经史子集— / —最多的」。
**原因**：断行点算在第一个 `—` 之后。
**解法**：断点表里对 `——` 单独处理，断在第二个之后：

```js
else if (plain[i] === '—' && plain[i+1] === '—') pts.push(i + 2);
```

### 字幕字号偏小

**现象**：电脑上正常，手机上要凑近看。
**原因**：按"有配音、字幕是辅助"给的值（49px）。
**解法**：纯画面时提到 **56px**（屏宽 5.2%）。有配音时可以回到 49–52px。

### 结尾金句折出孤字

**现象**：最后一行只剩一个「。」或一个字。
**原因**：自动断行不会考虑语义。
**解法**：这一句手动写 `<br>`，断行函数会跳过手写换行的句子。

## 三、叙事

### 画面文字和字幕复读

**现象**：整屏同一句话出现两次，观众读得累。
**原因**：没区分"书面金句"和"口播白话"。
**解法**：画面归硬数据和结论，字幕归解释和过渡。发布前逐条比对，完全相同的删一个。

复读有三种形态，肉眼最容易漏的是后两种：

| 形态 | 例子 | 怎么发现 |
|---|---|---|
| 整句重复 | 画面「目录不是书单」+ 字幕「目录不是书单」 | 一眼能看出来 |
| 短标签重复 | 画面四张卡「经 / 史 / 子 / 集」+ 字幕「经、史、子、集」 | 每块都太短，不像"一句话" |
| 数字重复 | 画面「3461 种 · 79309 卷」+ 字幕「著录 3461 种、79309 卷」 | 数字散在多个标签里，比对不上 |

三种都已经写进 `tools/check-js.mjs`（短标签按"字幕每个字都是画面上的独立标签"判定，数字按"场景内出现过的数字集合"判定）。
**改的时候不要只换同义词** —— 换成同义词观众照样读两遍，要让字幕去说画面没说出口的那层意思：

> 画面：`著录 3461 种 · 79309 卷`
> 字幕：~~最后成书：著录 3461 种、79309 卷~~ → **收进全书的，是这一栏**

---

### 结论没有数值锚点，只剩口号

**现象**：动画很漂亮，看完什么都没记住。
**原因**：只做了视觉奇观，没落具体数字。
**解法**：结论句必须包含一个数。「20 个客户，撑起 **80%** 的订单额」，不是「少数人贡献多数」。

### 长片靠一个奇观撑不住

**现象**：4 分钟后完播率断崖。
**原因**：单次反转只够撑 30 秒。
**解法**：每 40 秒一个新信息；2/3 处安排第二次反转推翻第一次的结论。参见 [方法论](01-method.md#两次反转)。

## 四、代码

### 比例算错，视觉上"看着假"

**现象**：条形长度和标注数字不成正比，说不上哪不对但就是假。
**原因**：宽度值手写，没按数据算。
**原错误代码**：

```js
// 错：对着 20 个点算 80%，但对 100 个总数算就成了 4%
const percent = Math.round(count / CONFIG.top * 100 * 0.8 * 10) / 10;
```

**解法**：先从原始数据算出比例常量，再乘：

```js
const RATIO = CONFIG.topAmount / CONFIG.totalAmount;  // 0.8
const percent = count / CONFIG.top * RATIO * 100;      // 每个点正好 4%
```

### `getTotalLength()` 对 `<text>` 无效

**现象**：描线动画里，文字所在的元素整个消失或突然闪现。
**原因**：`<text>` 没有路径长度，`getTotalLength()` 抛错或返回 0。
**解法**：文字单独走"线条画完后淡入"，用 `n * stagger` 算出延迟。见 [时间轴](03-timeline.md#描线动画)。

### CSS transition 干扰截图

**现象**：`?t=284&p` 截出来的图是半透明的、宽度只有一半。
**原因**：CSS 过渡由浏览器驱动，和 `t` 无关，跳到该帧后属性还在"渐变途中"。
**解法**：

```js
if (PAUSED) stage.classList.add('nofx');
```
```css
.nofx *{ transition:none !important; }
```

### `setTimeout` 驱动动画

**现象**：录屏卡一下之后，字幕和画面永久错位。
**原因**：定时器是独立时钟，掉帧不会补偿。
**解法**：一切动画由 `render(t)` 从 `t` 算出，禁止 `setTimeout` / `setInterval`。

## 五、插图

线描插图踩的坑最多，因为**小尺寸下的辨识度和屏幕上看完全不同**。

### 人物画成"雪人"

**现象**：一个圆脑袋下面接一根柱子。
**原因**：头半径 17，身体高度只有 100 —— 头身比 1:2.4。
**解法**：半身像至少 4 头身。头像直径 26 时，身高要有 108。立像**肩宽必须是头宽的两倍**，否则头比肩还宽。

### 简册被画成栅栏

**现象**：四根竖线两根横线，读者看成"井"字。
**原因**：竖线阵列在小尺寸下就是栅栏。
**解法**：减到 3 竖 2 横，且**竖线要有长短差**。最终还是不成立 —— 换成了"叠放的线装书"，识别度立刻对了。

### 小图标在 72px 下认不出

**现象**：四个卡片上方的图标，一个像栅栏、一个像变形窗口。
**原因**：72px 承载不了复杂结构，人眼要靠轮廓辨认。
**解法**：**直接删掉**。四张大字本身就是主体，图标是净负担。

> 通用判断：如果一个元素放大到 4 倍才认得出是什么，那它在成品里就是噪音。

### 插图被其它元素覆盖

**现象**：右上角的人物被八个大字完全盖住。
**原因**：绝对定位的元素没有参与布局，容易被后续内容叠上来。
**解法**：挪位置前先看整屏的视觉重心。八个 132px 金字已经占满时，正确做法是**不放插图**，而不是找地方塞。

### 印章像表格

**现象**：双层矩形框 + 一个字，读出来是"表格"。
**原因**：`<rect>` 太规整，不像刻石。
**解法**：用 16 个折点连成不规则多边形，做出崩口；去掉内框；字要撑满。

### 光晕比插图先亮

**现象**：截图里右上角悬着一团模糊的暖色光斑，附近什么都没有。同一条线画了 40 秒才出现。
**原因**：插图的光晕写在 CSS 上（`.art-tr{background:radial-gradient(...)}`），一进场景就亮；而线条由 `data-at` 控制，291.6 秒才落笔。**CSS 是"场景在就亮"，`data-at` 是"到点才画"，两套时钟。**
**解法**：光晕也交给 `t` 驱动，跟着 `data-at` 一起亮：

```css
.art-tr{ opacity:0; }   /* 初始必须是 0 */
```
```js
for (const h of HALOS){
  const v = pr(t, h.at, h.at + 1.0) * 0.9;
  if (h.o !== v){ h.o = v; h.el.style.opacity = v.toFixed(2); }
}
```

> 通用规则：**装饰性效果（光晕、投影、渐变底色）只要和插图的出现时间不一致，就一定会露馅。** 它们必须和插图共用同一个 `data-at`。

## 六、环境

### headless 截图失败 / 输出 0 字节

**现象**：命令行没报错，但图片是 0 字节或不存在。
**原因**：**文件路径含中文**。Windows 下 headless 对非 ASCII 路径经常静默失败。
**解法**：先复制到系统临时目录再截（`snap.mjs` 已内置）。

```bash
EDGE="/c/Program Files (x86)/Microsoft/Edge/Application/msedge.exe"
"$EDGE" --headless=new --disable-gpu --no-sandbox --hide-scrollbars \
  --window-size=1080,1920 --screenshot=out.png "file:///C:/temp/plain.html?t=30&p"
```

### 字体回退导致截图和实际不一致

**现象**：截图里字体是宋体，浏览器里是黑体。
**原因**：用了外部字体，headless 无网络。
**解法**：只用系统字体栈。这也是"单文件"原则的一部分。

### 录屏中途切窗口，画面跳帧

**现象**：成片中间突然跳了一段。
**原因**：`requestAnimationFrame` 在窗口失焦时被节流。
**解法**：录制期间不切窗口。因为时间轴挂在真实时钟上，掉帧只会**跳帧**不会拖慢，总长不变 —— 内容丢了，时长没错。

## 一条元规则

上面所有坑，有 80% 可以在**第 5 步逐帧验证**时发现。剩下 20% 是环境问题，症状很独特（0 字节、字体不对、半透明）。

所以：**改完立刻截图，不要攒到最后。** 一次改五处再截图，出了问题分不清是哪一处引起的。
