# 改稿话术

第一版几乎不可能对。**问题不在于 AI 画得不好，在于你的指令不够可测量。**

## 一条原则

> 说"改成什么"，不说"改得好一点"。

| ❌ 无效 | ✅ 有效 |
|---|---|
| 这个图好看点 | 这幅图的线太细，stroke-width 从 2.4 加到 3.2 |
| 字幕有点小 | 字幕字号从 49px 加到 56px |
| 动画太快 | 每个点亮的间隔从 0.25 秒改成 0.5 秒 |
| 排版不好看 | 内容全挤在顶部，中下部空了 600px，改成垂直居中 |
| 这个插图怪 | 删掉这个插图（一屏只有一个视觉重心） |

**带数字、带位置、带"改成什么"**，一次就成。

## 版式类

```
内容全挤在顶部，中下部大片空白 → 场景容器加 justify-content:center，
底部 padding 保留 340px 给字幕区。

内容被底部字幕压住了 → 内容总高超过了 1450px，把最下面那张卡片删掉，
或者把这一屏拆成两个场景。

这个大字和插图挤在一起，「年」字掉到第二行了 → 插图改成绝对定位的角标，
right:84px; top:128px，不占内容流。

卡片之间的间距太大 → gap 从 48px 收到 28px。
```

---

## 字幕类

```
字幕手机上太小 → 字号从 49px 提到 56px，行高 1.5。

「每一种 / 书」断在词中间了 → 加一个断行函数：
超过 16 个全角字才断，只在标点（，、：。？！；）之后断，
断点选最接近视觉中点的那个，破折号 —— 不能被拆开。

「经史子集— / —最多的」破折号被拆成两行了 → 
断点计算里对 —— 单独处理：检测到连续两个 — 时，断在第二个之后。

最后一行只剩一个字 → 这一句手动加 <br>，
断行函数遇到已经有 <br> 的句子要跳过。

字幕出现得太突然 → 淡入从 0 改成 0.34 秒，用 pr(t, 开始, 开始+0.34) 算，
不要用 CSS transition。

字幕和画面上的大字是同一句话 → 把画面那句改成书面金句，
字幕改成白话解释，两者不能有完全相同的句子。
```

---

## 节奏类

```
点亮太快，看不清个数在变 → 每点亮一个的间隔从 0.25 秒改成 0.5 秒。

结论出现得太急 → 最后一个点亮完之后，空 0.8 秒再让结论淡入。

开头没有铺垫，一上来就亮了 → 前 3 秒先让所有点以灰色浮现，
第 8.4 秒之后再开始点亮。

这一屏停留太久 → 从 40 秒压到 28 秒，后面场景时间整体前移。

整片结尾太快 → 最后一句字幕结束后留 4 秒空白，让画面自己收尾。
```

---

## 视觉类

```
点太小 → 每个点的直径从 48px 加到 68px，点阵的 gap 从 20px 加到 30px。

暗掉的点完全看不见，看不出"曾经有 288 个" → 
暗态不要用 #171A21 这种接近背景的颜色，改成空框：
背景透明 + 1px 描边 #33211F，opacity 0.3。

线条太暗，整体发灰 → 插图容器的 opacity 从 0.52 提到 0.9，
颜色从 #C9973A 提到 #D8A64C，底下加一层极淡的暖光径向渐变。

这个插图看不出是什么，删掉 → 这一屏的字已经够满了，加图只会打架。

这个人物比例不对，像个雪人 → 头身比至少 1:4，
头像直径 26 时身高要有 108；立像的肩宽必须是头宽的两倍。

印章看起来像表格 → 去掉内框，外框改成 16 个折点连成的不规则多边形，
做出刻石崩口的效果，里面的字撑满。

条形长度和标注的数字不成正比 → 宽度按 value / max * 条形轨道总宽 算，不要手写。
```

## 内容类

```
这一屏信息太多，观众来不及读 → 删掉副标题和第三个数据，
一屏只留一个视觉重心。

这里缺一个过渡，从上一屏跳过来了 → 加一句字幕解释因果。

结论太虚，看完记不住 → 结论句必须包含数字：
「20 个客户，撑起 80% 的订单额」，不要「少数人贡献多数」。

这个数字我没核实过 → 先留空，不要编。卡片上只放类数，卷数位置空着。

这里用了直角引号 → 全部换成中文弯引号 “”，全文不要出现「」。
```

## AI 改不对的时候

连续两轮没改对，说明描述不够"坐标系化"。改用**位置 + 尺寸 + 相对关系**描述：

```
不是"右上角那个图" —— 是：
场景 2 的画面里，位于 right:84px / top:128px、宽 300px 的那个 SVG。
它现在的问题：头部是一个正圆（circle cx=66 cy=86 r=17），
应该改成侧面轮廓线，用 path 画：额 → 鼻峰 → 人中 → 下巴，每处一个转折。
```

**给到元素级别**（哪个标签、哪个属性、改成什么值），AI 一次就能改对。这也解释了为什么模板里要有 `id` —— 有 id 才好指。

```bash
node tools/snap.mjs your-file.html 4 20 48 393
```
