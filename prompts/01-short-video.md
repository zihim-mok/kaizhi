# 短版提示词（15–40 秒）

一个奇观，一次反转，一句结论。适合「一个数字能说清一件事」的题材。

## 使用方式

先填好五栏表，把下面提示词里的 `{{}}` 替换掉，整段发给 AI。**不要边聊边改需求** —— 一次给全，出图更快。

---

## 提示词

```
我要做一个讲知识点的竖屏短视频，请生成一个单独的 HTML 文件（不引用任何外部资源）。

知识点：{{八成订单来自两成客户}}
反差点：{{重要的客户其实是少数}}
真实数据：{{总共 100 个客户，全年订单额 86 万元；其中前 20 名客户合计 68.8 万元，占 80%}}
可视化形式：{{10×10 点阵，每个点代表一个客户}}
结论句：{{20 个客户，撑起 80% 的订单额}}

【画面要求】
- 画布固定 1080×1920，等比缩放居中，两侧留黑不影响
- 深色背景（近黑 #05060A 加一层极淡的径向渐变），主色只用一种暖金，其余全部灰阶
- 除主色外不要用任何第二种彩色
- 所有文字用系统字体栈："PingFang SC","Hiragino Sans GB","Microsoft YaHei","Noto Sans SC",system-ui,sans-serif
- 数字用 font-variant-numeric: tabular-nums

【动画要求】
- 开头：所有点先以灰色浮现，间隔约 14ms 逐个出现
- 过程：第 8.4 秒开始，贡献最高的 20 个点逐个点亮金色，每个间隔 0.5 秒，同步显示"已点亮个数"和"金额占比"
- 结论：第 18.8 秒停在「20 个客户，撑起 80% 的订单额」，同时把点阵压暗到 opacity 0.26，让视线全部交给这句话
- 点亮的顺序要用固定种子的伪随机打散，不要集中在角落

【代码要求（重要）】
- 页面里必须有三个显式数据块：CONFIG（参数）、SCENES（场景时间表）、CUES（字幕稿），内容和样式严格分离
- 所有动画必须由 render(t) 从时间 t 直接算出，是纯函数：同一个 t 渲染同一个画面。禁止用 setTimeout / setInterval 驱动动画，禁止累积状态
- 主时钟用 performance.now()，不要用帧计数
- 支持网址参数：?t=秒数 跳到该时刻，?t=秒数&p 停在该帧并禁用所有 CSS transition（否则截图会截到过渡中间态），?clean 隐藏右下角提示
- 快捷键：空格重播，F 全屏，H 切换提示显示

【字幕要求】
- 字幕内嵌在 HTML 里，由 CUES 数组驱动，格式 [开始秒, 结束秒, 文本]，和动画读同一个 t
- 一句话一屏，每句 8–16 个全角字，句间留 0.2 秒空隙
- 字幕字号 56px，字重 600，行高 1.5，居中，带 text-shadow: 0 2px 24px rgba(0,0,0,.9)
- 超过 16 字的句子要自动断行：只在标点（，、：。？！；）之后断，断点选择最接近视觉中点的那个；破折号 —— 不能被拆到两行；如果原句里已经写了 <br> 就尊重手写换行
- 字幕负责白话解释，画面文字负责书面结论和数字，两者不允许出现完全相同的句子

生成后告诉我：1) 怎么在浏览器里打开 2) 每一句字幕对应的秒数 3) 哪个数字是算出来的、怎么算的。
```

## 替换要点

| 占位 | 填什么 | 注意 |
|---|---|---|
| 知识点 | 一句话，25 字内 | 不是学科名，是结论 |
| 反差点 | 跟直觉相反的那半句 | 只填一个 |
| 真实数据 | 原始数字，含总数和子集 | **必须先自己核完** |
| 可视化形式 | 点阵 / 条形 / 时间轴 / 节点链 | 只选一种 |
| 结论句 | 带数字的一句话 | 不能只有形容词 |

## 提示词里为什么有那几条「代码要求」

这些不是洁癖，是省返工：

- **三块数据分离** → 改内容时不用在 800 行里找
- **render(t) 纯函数** → 才能 `?t=` 跳转、才能逐帧截图
- **禁用 transition** → 否则测试截图全是半透明中间态
- **断行规则** → 否则一定会出现「每一种 / 书」
- **不允许复读** → 否则整屏同一句话出现两次

不加这几条，AI 也会给你一个"能播"的页面，但改不动、验不了、字幕难看。第一次生成时多写 200 字，后面省两小时。

## 出图后的自检

- [ ] 点亮的 20 个点是打散的，不是聚在左上角
- [ ] 计数到 20 时，占比正好 80%
- [ ] 结论出现后，背景确实压暗了
- [ ] 空格重播，点阵回到全灰
- [ ] `?t=20&p` 截出来是停在结论那一帧，不是半透明

不合格就进 [改稿话术](03-revise.md)。
